👄 입술·입안 관리

입술 (하루 3번 소독, 아침·저녁엔 연고까지)
  1. 수포란 스프레이를 입술·딱지·턱에 여러 번 뿌리기 (또는 식염수 거즈 3~5분 올려 딱지 불리기)
  2. 거즈로 톡톡 눌러 닦기 — 문지르거나 딱지 떼지 않기
  3. 깨끗해질 때까지 1~2 반복
  4. 마지막으로 한 번 더 뿌리고 30초~1분 그대로 말리기
  5. 물기 톡톡 → 무피로신 연고 얇게 (아침·저녁)
입안
  • 🔄 11/4 빈멕 재진: 수포란으로 입안도 세척 — 입안·혀에 뿌리거나 거즈에 묻혀 살살 닦고, 삼키지 말고 뱉기
  • 식후마다 + 자기 전 수포란 가글 → 뱉기 (11/2엔 식염수 거즈)
  • 아파서 못 먹으면 약국에서 Kamistad-Baby gel → 밥 10~15분 전 헌 곳에 얇게

⏰ 아이폰 알림 켜기

아래 버튼을 누르면 7일치 약 시간 48개가 아이폰 캘린더에 들어가고, 시간마다 알림이 울려요. 앱을 안 열어도 돼요.

📅 캘린더에 알림 추가
  1. 사파리에서 이 페이지를 열고 위 버튼 누르기 (디스코드·카톡 안에서 열렸으면 오른쪽 위 ⋯ → 사파리로 열기)
  2. 「이벤트 48개 추가」 → 모두 추가
  3. 설정 → 캘린더 → 알림이 켜져 있는지 확인
